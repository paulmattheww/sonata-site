Before you start

A few good questions.

Is Sonata for someone at my level?

Sonata is a practice companion for exploring classical pieces, slowing passages down, and working on each hand separately. Beginners can start with simpler pieces; intermediate and returning players can use the same tools to work through harder sections. It is not a replacement for a teacher or a complete course in piano technique.

Do I need a MIDI keyboard?

No. You can use the on-screen piano, connect a compatible keyboard over USB or Bluetooth MIDI, or use the microphone with an acoustic piano. The connection method depends on your keyboard and any adapter it requires.

How does acoustic practice work?

The microphone listens for the notes you play. Detection can vary with the instrument, room, microphone position, and chords or sustained notes. Replay and skip controls help when a note is not picked up. MIDI sends note messages directly instead of relying on microphone detection.

Does the falling-note guide work on iPhone?

The new optional guide is for iPad in version 1.0.6, currently in TestFlight. iPhone practice uses the sheet-music and piano-keyboard view. The demo on this page previews the updated iPad interface, not a live microphone-recognition test.

Can I practice without internet?

The scores and piano samples are bundled with the app. Purchases, restoring access, and periodic subscription checks still need an internet connection.

What should I try first?

Pick a piece you know, reduce the tempo, and try one hand. Loop a short passage before moving on. If you have a keyboard, try MIDI input; if you are using an acoustic piano, start with a quiet room and a simple passage.
